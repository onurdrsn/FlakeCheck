Frequently Asked Questions

What is FlakeCheck?

FlakeCheck (also known as Flake Check or flake-check) is an open-source flaky test detector that ingests CI test reports, computes statistical flakiness scores, diagnoses root causes, and quarantines unstable tests.

Which test frameworks and CI systems are supported?

FlakeCheck supports JUnit XML, CTRF, Jest, Vitest, Playwright, Pytest, Mocha, and Go test JSON, with ready-to-use templates for GitHub Actions, GitLab CI, CircleCI, and Jenkins.

Does FlakeCheck require an SDK inside my tests?

No. FlakeCheck works out of the box with standard test report files via the CLI or authenticated CI webhooks.
